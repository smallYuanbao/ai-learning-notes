# 日志系统

> 📅 学习日期：2026-08-08
> 🔗 关联面试题：工程化专题 日志/监控相关题目

## 1. 为什么需要日志系统
- 开发阶段靠 `print()` 调试，但生产环境需要持久化、分级、可查询的日志
- 日志系统提供 DEBUG/INFO/WARNING/ERROR 四级，不同环境可配不同级别
- 文件轮转防止日志无限增长

## 2. 我的实现
- 代码位置：`app/utils/logger.py`
- 控制台输出：DEBUG 级别，开发时实时查看
- 文件输出：INFO 级别，写入 `logs/app.log`，10MB 轮转，保留 3 个备份
- 统一格式：`时间 | 级别 | 模块 | 消息`

## 3. 面试怎么讲
> “我用 Python 内置的 logging 模块搭建了日志系统。控制台输出 DEBUG 级别方便开发调试，文件输出 INFO 级别用于生产排查。日志按大小自动轮转，不会撑爆磁盘。关键节点（请求到达、LLM 调用、异常降级）都有日志记录，配合降级策略可以快速定位问题。”

## 4. 项目关联
- 日志配置：`app/utils/logger.py`
- 启动初始化：`app/main.py`
- 关键节点日志：`app/services/agent.py`、`app/services/llm.py`
