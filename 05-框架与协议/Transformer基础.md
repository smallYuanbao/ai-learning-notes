## 1. Transformer 概念

Transformer 是一种革命性的深度学习模型架构，它完全基于“注意力机制”来处理序列数据。

Tranformer 是当前所有主流大模型的“始祖”和“地基”。

## 2. 解决了什么问题

在 Transformer 出现之前，处理语言的主流模型是RNN（循环神经网络）。RNN 处理文本像人“按顺序读书” --- 必须一个字一个字读，读完第1个字才能读第2个字。

- 致命缺陷1（串行慢）：无法并行计算，训练极慢，浪费GPU算力。

- 致命缺陷2（遗忘/长距离依赖）：如果句子很长（比如1000字），RNN读到末尾时，早就忘了开头在讲什么（“梯度消失”）。

Transformer的解法：抛弃顺序，只看全局。它允许模型一眼看完整个句子，并自动判断“哪些词之间关系密切”。

**用你已经熟悉的类比**：

| 你熟悉的 | Transformer 里的对应 |
|---------|-------------------|
| 前端的事件冒泡（一个元素能感知到整个 DOM 树） | Self-Attention（一个词能“看到”整个句子中的所有词） |
| 数据库的联合查询（多表关联） | 多头注意力（从不同角度捕捉词与词的关系） |
| 你的 `rerank` 函数（Cross-Encoder 同时看 query 和 doc） | Self-Attention（同时看句子中所有词） |

**关键理解**：你项目中用的 BGE Reranker 是 Cross-Encoder——把 query 和 doc 拼在一起做全注意力计算。Transformer 的 Self-Attention 也是这个思想，只是它是在同一个句子内部，让每个词关注其他所有词。

## 3. 核心底层机制--自注意力机制（Self-Attention）

简单来说，它会自动计算这个词与句中其他所有词之间的“亲密度”（权重），从而精确理解语境。

通俗类比：看简历找关键词
假设你是一个HR，面对一份超长的简历（待处理的文本），你不会一个字一个字地读，而是目光扫视，注意力自动集中在“985”、“阿里”、“Python”这些关键词上。

- Transformer 的 自注意力（Self-Attention） 就是这种“扫视”能力的数学化版本。

- 它通过 Q（查询 Query）、K（键 Key）、V（值 Value） 这三个矩阵运算，计算出每个词对其他词的“权重”（注意力分数），权重越高，代表模型越“关注”那个词。

> 例子：句子“那个追着白猫的小狗跑得很快。”
> 当模型处理“小狗”这个词时，注意力机制会赋予“追着”（动作）和“白猫”（宾语）极高的分数，而对“很快”赋予中等分数，对“的”赋予极低分数。这样模型就理解了“谁在干什么”。

### 3.1 核心思想

**Self-Attention 的核心思想是：对于句子中的每个词，计算它和所有其他词的相关性，然后加权求和，得到一个新的表示。**

三个核心矩阵：

| 矩阵 | 含义 | 类比 |
|------|------|------|
| Q（Query，查询） | “我正在找什么？” | 你在搜索引擎里输入的关键词 |
| K（Key，键） | “我是什么？” | 每篇文档的标题和摘要 |
| V（Value，值） | “我包含什么内容？” | 每篇文档的正文 |

### 3.4 计算步骤

1. 每个词通过三个不同的线性变换，得到自己的 Q、K、V 向量

2. 计算 Q 和所有 K 的点积，得到“注意力分数”（这个词和其他词有多相关）

3. 用 Softmax 把分数转为概率（所有分数加起来 = 1）

4. 用概率对 V 加权求和——这就是这个词“关注了所有其他词之后”的新表示

一句话总结：Q 和 K 决定“关注谁”，V 决定“拿到什么信息”。

### 3.5 和你的项目关联

| Self-Attention 中的操作 | 你项目中的对应 |
|----------------------|-------------|
| Q 和 K 做点积 | Dense 检索中查询向量和文档向量做余弦相似度 |
| Softmax 转概率 | RRF 中的排名融合（把排名转成分数） |
| V 加权求和 | 把检索到的文档拼入 Prompt（关注最相关的文档） |
| 整个 Self-Attention 层 | 你的 Cross-Encoder Reranker（query 和 doc 做全注意力计算） |

**关键理解**：你项目中的 RAG 检索本质就是“句子级别的 Self-Attention”——查询是 Q，知识库文档是 K 和 V，检索就是找到最相关的 V 并注入 LLM。

## 4. 整体架构

原始论文提出的 Transformer 是一个 Encoder-Decoder（编码-解码）结构，但现代大模型通常只保留了其中的“解码器”部分

| 组件 | 作用 | 谁在用 |
|------|------|------|
| 编码器（Encoder） | 读取完整输入文本，将每个词编码成富含上下文信息的向量。擅长理解（双向注意力） | BERT 系列模型 |
| 解码器（Decoder） | 根据语义向量逐字逐句生成新文本（从左到右单向注意力）。擅长生成 | GPT、DeepSeek 系列模型 |

> 关键点：你现在调用的 DeepSeek API，其背后的模型就是一个巨大的“仅解码器（Decoder-Only）” Transformer 架构。


## 5. 核心三大优势

| 优势 | 说明 |
|:---:|------|
| ① 并行计算 | 不依赖顺序，可一次性把整段话扔进 GPU 同时计算，训练速度极快 |
| ② 捕获长距离依赖 | 无论句首和句尾隔多远，注意力机制都能直接计算关系，无信息衰减 |
| ③ 可解释性强 | 可视化注意力权重，直观看到模型在”看”哪里 |


### 5.1 为什么 Transformer 能统治科技界？

- 支持暴力美学（Scalability）：它对显卡极度友好。只要你有足够的 GPU、足够多的数据，Transformer 的智商就能随着模型变大而无上限地飙升（这就是大模型“涌现”现象的来源）。
- 万物皆可 Transformer：它不仅能处理文本。如果把图片切成一格一格的方块（Patch）喂给它，它就变成了 ViT（Vision Transformer），能看懂图像；如果喂给它多维数据，它就能预测蛋白质结构（AlphaFold 3）。


## 6. 位置编码、多头注意力、残差连接 + 层归一化


### 6.1 位置编码

- 痛点：注意力机制有一个致命缺陷--它把句子当成一堆无序的词语包。对于模型来说，“小狗咬我”和“我咬小狗”在注意力计算下，词与词的关联强度可能一模一样（因为都有“小狗”和“我”）

- 解法：在把词向量喂给模型前，强行加一个代表“顺序”的向量进去。这相当于给每个词发一个带有“位置编号”的身份证。

    - 早期（原始Transformer）：用正弦/ 余弦函数生成固定的位置向量（像无线电波频率）

    - 现在主流（DeepSeek/GPT）：改用RoPE（旋转位置编码）。它不直接把位置数字加上去，而是把词向量在数学空间里“旋转”一定的角度。离的远的词旋转角度大，离的近的旋转角度小。模型看两个词的距离，只需要看它们的向量夹角即可，效果极好且极省算力。
- 大白话：每个人去餐厅吃饭（输入词向量），不仅要登记你叫什么（语义），还要在你的衣服上贴一个排队号码牌（位置编码）。这样 AI 就能通过号码牌的差值，立刻知道哪两个词离得近，哪两个词离得远。


### 6.2 多头注意力机制

- 痛点：单次注意力机制“太死板”。它计算出的权重只有一个结果，容易”一叶障目“。例如，分析“苹果发布了新手机，股价随之上涨”，单头注意力可能只盯着“苹果”和“手机”的关系，完全忽略了“股价”。

- 解法：把注意力机制复制成 N 份（通常 8~96 个“头”），每个头独立计算，最后把 N 个结果拼在一起。

    - 头 A（语法专家）：专门盯着“主谓宾”结构（关注词性）。

    - 头 B（语义专家）：专门盯着“苹果”和“股价”（关注逻辑关联）。

    - 头 C（位置专家）：专门盯着距离很远的词（长距离依赖）。

        最终：模型综合 8 个专家的意见做决策，远比一个专家看得全面。这也是大模型能力远超小模型的关键：“头”越多，模型能捕捉的“特征维度”越丰富。

- 大白话：面对一桩复杂的案件（一句话），不只派一个侦探去看，而是派一个专家侦探团（多头）。
    - 头 1 专门盯着句子的代词指代（“他”指的是谁？）。
    - 头 2 专门盯着句子的动宾搭配（这个动作是谁发出的？）。
    - 头 3 专门盯着句子的修饰语（这个形容词在形容哪个名词？）。最后大家开会把线索汇总，AI 从而获得极其立体的语义理解。

### 6.3 残差连接 + 归一化

这是模型能堆叠成百上千层（DeepSeek V3 有 671B 参数，几百层）而不会”崩塌”的两个黄金搭档。

**残差连接**：

- 痛点：神经网路层数太多时，信号（梯度）在层层传递中衰减（梯度消失），导致前面的层根本学不到东西。

- 解法：在每一层计算完之后，把每一层的“原始输入"原封不动的加回来。

- 公式：输出 = 原始输入 + 本层处理结果。

- 类比：就像高速公路旁边的“紧急停车带”。车子（数据）在主路（网络层）上堵车了（难以反向传播），可以直接借道快速绕过去。这样，模型哪怕有 1000 层，梯度的“火种”也能直接传回第一层。

**归一化**：

- 痛点：经过多头注意力和残差加法后，数值范围会变得忽大忽小（有的变成 100，有的变成 0.001），模型很难收敛（训练不稳）。

- 解法：在每次输出前，强行把这一批数据的均值和方差拉回标准正态分布（均值为0，方差为1）。

- 类比：就像音频剪辑师调节音量。不管上一句是尖叫（数值大）还是低语（数值小），归一化都把它调成“正常说话的音量”，确保下一层处理时不会“过载（梯度爆炸）”或“听不见（梯度消失）”。

### 6.4 汇总

| 设计 | 一句话解释 | 为什么重要 |
|------|------|------|
| **位置编码** | 给每个词加上它在句子中的位置信息 | Transformer 是并行的，不按顺序处理，需显式告诉模型位置 |
| **多头注意力** | 用多组不同的 Q/K/V 矩阵，从不同角度捕捉关系 | 就像用多个滤镜看同一张图——一个关注语法，一个关注语义 |
| **残差连接 + 层归一化** | 每层的输出 = 输入 + 注意力结果，然后归一化 | 解决梯度消失，让模型可以堆几百层 |


## 7. 手写 Self-Attention（NumPy）

### 7.1 核心代码

```python
import numpy as np

def softmax(x):
    """Softmax 函数：把任意向量转成概率分布（所有值加起来=1）"""
    exp_x = np.exp(x - np.max(x))  # 减最大值防止溢出
    return exp_x / exp_x.sum(axis=-1, keepdims=True)

def self_attention(X, d_k=4):
    """
    极简 Self-Attention 实现

    参数：
        X: 输入矩阵，形状 (seq_len, d_model)，每行是一个词的向量
        d_k: Q/K 的维度

    返回：
        output: 注意力加权后的新表示，形状 (seq_len, d_model)
        attention_weights: 注意力权重矩阵，形状 (seq_len, seq_len)
    """
    seq_len, d_model = X.shape

    # 1. 随机初始化 Q/K/V 的权重矩阵（实际训练中这些是通过学习得到的）
    W_Q = np.random.randn(d_model, d_k) * 0.1
    W_K = np.random.randn(d_model, d_k) * 0.1
    W_V = np.random.randn(d_model, d_k) * 0.1

    print("Q 权重矩阵形状:", W_Q.shape)  # (d_model, d_k)
    print("W_Q 矩阵内容:\n", W_Q)
    print("K 权重矩阵形状:", W_K.shape)  # (d_model, d_k)
    print("W_K 矩阵内容:\n", W_K)
    print("V 权重矩阵形状:", W_V.shape)
    print("W_V 矩阵内容:\n", W_V)

    # 2. 计算 Q、K、V
    Q = X @ W_Q  # (seq_len, d_k)
    K = X @ W_K  # (seq_len, d_k)
    V = X @ W_V  # (seq_len, d_k)

    print("Q 矩阵形状:", Q.shape)  # (seq_len, d_k)
    print("Q 矩阵内容:\n", Q)
    print("K 矩阵形状:", K.shape)  # (seq_len, d_k)
    print("K 矩阵内容:\n", K)
    print("V 矩阵形状:", V.shape)  # (seq_len, d_k)
    print("V 矩阵内容:\n", V)

    # 3. 计算注意力分数：Q 和 K 的点积，除以 sqrt(d_k) 做缩放
    scores = Q @ K.T / np.sqrt(d_k)  # (seq_len, seq_len)

    # 4. Softmax 转为概率
    attention_weights = softmax(scores)  # (seq_len, seq_len)

    # 5. 用概率对 V 加权求和
    output = attention_weights @ V  # (seq_len, d_k)

    return output, attention_weights

# ==================== 运行示例 ====================

if __name__ == "__main__":
    # 模拟一个句子：4 个词，每个词用 6 维向量表示
    # 假设句子是 "宝宝 发烧 怎么 办"
    X = np.array([
        [0.8, 0.3, 0.1, 0.5, 0.2, 0.7],  # 宝宝
        [0.2, 0.9, 0.4, 0.3, 0.6, 0.1],  # 发烧
        [0.5, 0.1, 0.8, 0.2, 0.3, 0.4],  # 怎么
        [0.1, 0.4, 0.2, 0.9, 0.5, 0.3],  # 办
    ])

    output, attn = self_attention(X)

    print("输入形状:", X.shape)          # (4, 6)
    print("输出形状:", output.shape)     # (4, 4)
    print("\n注意力权重矩阵 (4x4):")
    print("      宝宝    发烧    怎么    办")
    for i, word in enumerate(["宝宝", "发烧", "怎么", "办"]):
        print(f"{word}  {attn[i]}")

    print("\n解读：每一行表示这个词对句子中所有词的注意力分布")
    print("例如 '宝宝' 行中值最大的列，表示 '宝宝' 最关注哪个词")
```

### 7.2 代码解释

| NumPy 代码 | 对应 Transformer 中的 |
|---|---|
| `X @ W_Q` | 把输入词向量通过线性变换得到 Q |
| `Q @ K.T` | 计算 Q 和所有 K 的点积，得到注意力分数 |
| `np.sqrt(d_k)` | 缩放因子，防止点积过大导致 Softmax 梯度消失 |
| `softmax(scores)` | 把分数转成概率分布 |
| `attention_weights @ V` | 用概率对 V 加权求和，得到新的词表示 |

## 8. 面试怎么讲

> “Transformer 的核心是 Self-Attention 机制。它让句子中的每个词都能直接关注到其他所有词，计算两两之间的相关性，然后加权求和得到新的词表示。具体来说，每个词通过三个线性变换得到 Q（查询）、K（键）、V（值）三个向量。Q 和 K 做点积得到注意力分数，Softmax 转成概率，再用概率对 V 加权求和——这就是这个词‘关注了所有其他词之后’的新表示。

> 和我的项目关联：RAG 检索本质就是句子级别的 Self-Attention——用户问题是 Q，知识库文档是 K 和 V，检索就是找到最相关的 V 并注入 LLM。我用的 Cross-Encoder Reranker 就是 Q 和 K/V 做全注意力计算，输出相关性分数。”
